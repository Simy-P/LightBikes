# LightBikes

Neon light-cycle game for the browser, phones and Meta Quest (WebXR). Blue vs red, 90° turns, speed control, procedural synthwave soundtrack.

**Play:** https://simy-p.github.io/LightBikes/

- **1 player:** 10 levels, Easy / Normal / Hard, gold pickups that wipe every trail off the grid.
- **2 player online:** pick a bike tag, enter the lobby, tap a rider to challenge them. The challenger hosts; both riders must agree to a rematch.
